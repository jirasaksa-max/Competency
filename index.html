⚡ Backend Integration & REST API Specification

คู่มือ RESTful API Endpoints สำหรับวิศวกร Backend นำไปเขียนต่อเชื่อมต่อฐานข้อมูล SQL/NoSQL ได้ทันที

① GET /api/v1/competency/summary
// Response 200 OK { "year": 2024, "totalEvaluated": 281, "breakdown": { "office": 124, "sales": 102, "lasik": 56 }, "levels": { "staff": 233, "supervisor": 34, "manager": 14 }, "corporateObjective": { "kpi": "Entrepreneurship Gap", "target": 30.0, "actual": 20.64, "passed": true, "prev": 22.67 } }
② GET /api/v1/competency/core-gaps?level={level}&dept={dept}
// SQL Query Example SELECT c.name AS competency_name, COUNT(*) AS total_evaluated, SUM(CASE WHEN e.score < e.expected_level THEN 1 ELSE 0 END) AS gap_count, ROUND(SUM(CASE WHEN e.score < e.expected_level THEN 1 ELSE 0 END) * 100.0 / COUNT(*), 2) AS gap_pct FROM evaluations e JOIN competencies c ON e.competency_id = c.id WHERE c.type = 'core' GROUP BY c.id, c.name ORDER BY gap_pct DESC;
